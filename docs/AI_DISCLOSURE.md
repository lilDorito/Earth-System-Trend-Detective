# AI use disclosure

Everyone on the team used Claude Pro, mostly Claude Code and Cowork.

**What AI did.** Claude wrote most of the code: the data pipeline, the statistics, the API and the interface. We also used it to debug, optimize, and review each other's changes.

**What we did.** The ideas are mostly ours: what the product should be, which questions it should answer, which data to use and how to present it. We made the decisions along the way, tested the results, and rejected or redirected what didn't fit. Through that we shaped the product. We understand all of the logic in the repository and can explain any part of it.

**Data and results.** Every number in the app comes from the datasets listed in the [README](../README.md), processed by the code in this repository. Nothing on the map or in the panels is generated by AI.
